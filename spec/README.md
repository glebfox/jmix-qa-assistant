# Project Specification

This directory holds the specification of the Jmix QA Assistant project — what the project is, what is in scope for the current MVP, what is deferred, and how the pieces fit together.

Read this directory when you are **developing** the project: evolving scope, planning future work, changing the helper script, deciding what belongs in the knowledge base. For operating the assistant (generating checklists, authoring knowledge modules), see [../docs/](../docs/) instead.

## Contents

- [scope.md](scope.md) — what the current MVP includes and excludes.
- [roadmap.md](roadmap.md) — MVP 2 and deferred work.
- [launch-plan.md](launch-plan.md) — pilot plan for validating the workflow.
- [kb-tool.md](kb-tool.md) — the helper script (`kb_tool.py`): what it does, what it does not, and how to change it.
- [mvp2-regression-seeds.md](mvp2-regression-seeds.md) — early draft material for the MVP 2 regression knowledge base. Not consulted by the assistant.
