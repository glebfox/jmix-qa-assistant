## Questions
- Which built-in UI texts are provided by the component?

## Checklist
### I18n
- Verify message keys for the component built-in UI text.
- Verify available localization for known supported languages.

## Risks
- Built-in component text can bypass application message bundles and appear as hard-coded text in localized applications.
